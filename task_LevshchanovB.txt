Индивидуальное задание для LevshchanovB (группа 9)
Диапазон строк в файле labdata-9.log: 891-896

1. Создайте директорию, посвященную Linux, в ней создайте поддиректории с именами основных современных дистрибутивов.
2. В каждой директории посвященной дистрибутиву создайте файл info.txt, содержащий на отдельных строках его полное название, название используемой среды рабочего стола, краткое описание особенностей, дату выхода последней актуальной версии.
3. В корневой директории создайте файл в котором будут объединены только последние строчки всех файлов info.txt (рекомендуется использовать команду tail)
4. С помощью команд head и tail выведите вторую строку любого файла info.txt в новый файл
5. Перейдите в директорию os-labs/students-2026 из Лабораторной Работы №1 и загрузите из репозитория последнюю версию. В ней находится множество файлов с информацией о студентах с ожидаемым форматом названия: ФамилияИО
Выведите в терминал имена (первые строки txt файлов) всех студентов, фамилия которых в названии состоит ровно из 7 символов.
